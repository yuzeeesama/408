# 408 刷题网站（王道 2027）

计算机考研 408 四科（数据结构、计算机组成原理、操作系统、计算机网络）在线刷题网站。

## 功能
- **选择题练习**：按科目/章节逐题作答，提交后显示对错、正确答案与解析；答错自动进入错题本（本机 localStorage）。
- **综合应用题辅导**：先看思路引导，自己动笔后再点「显示解答」。
- **错题本**：本机保存、展开解析、删除、导出 JSON。
- **学习统计**：各科已做题数与正确率。
- 答案默认隐藏，需作答或点击后才显示。

## 数据
- 题库来自《王道 2027 考研复习指导》四科教材（扫描 OCR 提取），共 2708 道（选择题 2276 + 综合应用题 432）。
- 计算机网络的选择题（564 道，答案与解析齐全）已改用 `book/题库output/计网/` 的视觉转写版；其余科目仍为教材 OCR 版。
- 含图题目（选择题与大题）自动裁剪教材/做题本中的配图，随题干与解答展示。
- 数据文件：`data/*.json`（`数据结构/操作系统/计组` 由 `../408-grading/scripts/build_site.py` 生成；`计网` 由 `tools/booklet/update_web.py` 生成）。

## 本地运行
```bash
cd 408-quiz
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署（GitHub Pages）
推送到仓库后，在 Settings → Pages 选择 `main` 分支 `/` 目录即可。
